A small OS.
Running native code.

Treas runs one native application inside a fresh virtual machine, then returns its output straight to your terminal.

Explore the project ↗ Run it locally ↓

01

Native, isolated

Run a guest application in its own virtual machine. KVM when available, TCG otherwise.

02

Small by design

A compact kernel, a versioned syscall ABI, and shared-memory I/O.

03

Built to explore

Processes, threads, virtual memory, events, and a freestanding C SDK.
